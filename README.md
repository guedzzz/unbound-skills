# Unbound skills

Free skills for AI agents working on the Unbound HubSpot theme.

Each folder is one concern. Read the skill whose description matches the task. These skills apply to Unbound only.

| Skill | Use when |
| --- | --- |
| [unbound-hero-banner](skills/unbound-hero-banner/SKILL.md) | Editing the Hero Banner module |
| [unbound-feature-cards](skills/unbound-feature-cards/SKILL.md) | Editing Feature Cards |
| [unbound-spacer](skills/unbound-spacer/SKILL.md) | Editing the Spacer (space or a rule, not a shape) |
| [unbound-theme-settings](skills/unbound-theme-settings/SKILL.md) | Editing theme settings |
| [unbound-section-dividers](skills/unbound-section-dividers/SKILL.md) | Adding a section-edge divider shape |
| [unbound-templates](skills/unbound-templates/SKILL.md) | Composing a page, blog, or system template |

The shape menu in the divider skill is locked: Wave, Soft wave, Slant, Arch, Arch offset, Paper cut, Triangle, Triangle offset, Arrow, Split, Book, Peaks, Steps, Corner cut, Rounded corner, Blob.
